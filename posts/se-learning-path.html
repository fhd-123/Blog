软件工程本科四年，我学到的最重要的几件事

2026-03-02 · 傅浩东

临毕业回头看，课堂上学到的语法和框架只是起点，真正让我在项目中少走弯路的，是一些「软」却关键的习惯。这里记录几点对我影响最大的。

一、先把问题说清楚，再写代码

很多 Bug 源于对需求理解偏差。现在我拿到任务会先确认：输入是什么、边界在哪、失败怎么处理。想清楚再动手，比边写边改省十倍时间。

二、数据库思维比框架思维更底层

Spring 全家桶会过时，但「数据如何存储、如何被高效查询」是恒久的。索引、事务、锁这些概念，是我做项目时最常被用到的武器。

三、用工程化方式协作

Git 提交信息写清楚、接口文档提前对齐、改动小步提交——这些看似琐碎的规范，决定了团队能不能高效并行。

四、输出倒逼输入

把学过的东西写成文章（比如这个博客），会逼自己把模糊的理解理顺。写不出来的地方，往往就是没真懂的地方。

四年很短，但把这几件事做对，足够支撑我走向下一段旅程。
